# Contributing to Awesome Free Tools

Thank you for wanting to contribute! This list gets better with community input.

## How to add a tool

1. **Fork** this repository
2. **Add your tool** to the correct category in `README.md`, in alphabetical order
3. Use this format:
   ```
   | [Tool Name](https://link.com) | One-line description of what it does and why it's useful. |
   ```
4. **Submit a Pull Request** with the title: `Add [Tool Name] to [Category]`

## Requirements for a tool to be included

- ✅ Must be **free** (free tier is fine, freemium is OK if the free tier is genuinely useful)
- ✅ Must be **working** and **actively maintained**
- ✅ Must be **safe** (no malware, no shady practices)
- ✅ Must be **useful** to a general audience
- ❌ No referral links or affiliate links
- ❌ No tools that are free only for a trial period

## Updating or removing a tool

If a tool has gone paid, shut down, or is no longer recommended, please open an Issue or PR to remove it.

## Code of Conduct

Be respectful. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
